# Executive Privacy & Telemetry Audit Brief: T3 Code Peers & Open-Source Agent Harnesses

**Audited Scope:** **25 open-source repositories** (`13` Group A T3 Code desktop/web GUI peers + `12` Group B popular agent harnesses/CLIs), plus **T3 Code** baseline (`4c2e2b37`, **`F`**) → live `HEAD` (`2b84f486`, **`D`**) delta.

## Rating Distribution & Core Ecosystem Verdict

- **Clean (`A` — Zero Product Telemetry or Strict Fail-Closed Opt-In): `3`** — **Aether**, **Roo Code** *(archived 2026-05-15)*, **Hermes** *(stale FAQ wording alone does not penalize strict fail-closed runtime privacy)*
- **High-Privacy (`B` — Hard-Disabled Local Telemetry w/ Minor Boot Plumbing): `1`** — **Vibe Kanban**
- **Moderate / Privacy-Conscious Core (`C`): `4`** — **Orca**, **Happy**, **Goose**, **Pi** *(strong schema/GeoIP/opt-in/zero-SDK engineering with fixable startup-fetch, DNT, pre-opt-out edge, or documentation flaws; notably, zero default-on platforms achieved an unblemished `C` with full `DO_NOT_TRACK` + IP/model + doc compliance)*
- **Aggressive / Leaky (`D`): `11`** — **T3 Code** *(Live `HEAD`)*, **Emdash**, **Crystal**, **Nimbalyst**, **Pane**, **Traycer** *(borderline `F`)*, **OpenCode**, **OpenAI Codex CLI**, **OpenHands**, **Aider**, **Continue**
- **Severe Red Flags (`F`): `6`** — **Paradev (Superset)**, **AionUi**, **Opcode (Claudia)**, **Google Gemini CLI**, **Cline**, **Kilo Code** *(plus **T3 Code Baseline `4c2e2b37`**)*
- **`DO_NOT_TRACK` support:** **Only 1 of 25 platforms (`Orca`) cleanly honors `DO_NOT_TRACK`** across telemetry and diagnostic uploads (`Pane` and `OpenHands` support it partially with verified leaks/bypasses; **22 platforms ignore it completely**).

## Biggest Takeaways for Practitioners

1. **Six highest-risk tools (`F`):** Avoid official builds of **Kilo Code** unless `KILO_DISABLE_SESSION_INGEST=1` (in addition to `KILO_TELEMETRY_LEVEL=off`) is enforced; **Paradev/Superset** (Desktop/Mobile/CLI opt-outs do not exist); **AionUi** (un-opt-outable Sentry + 24h 19 MiB unredacted log upload); **Opcode (Claudia)** (silent pre-set `{ enabled: true, hasConsented: true }` + unmounted consent UI + outright false `"No Telemetry"` README); **Google Gemini CLI** (set `"privacy": { "usageStatisticsEnabled": false }`, `"telemetry": { "enabled": false, "logPrompts": false }`, and opt out of `/privacy` Free-tier training, noting `recordCodeAssistMetrics` remains active on Google auth); and **Cline** (7 active bypasses + `CLINE_TRACE_RECORD_CONTENT="true"` OTLP prompts + unconditional `node-machine-id`).
2. **Best privacy-first choices (`A` / `B`) & solid middle tier (`C`):** **Aether (`A`)** for zero telemetry (accepting local Claude/Codex quota reads); **Roo Code (`A`, archived)** for telemetry-free VS Code/CLI operation; **Hermes (`A`)** for strict fail-closed opt-in telemetry (set `auth.adopt_external_logins: false` and `updates.check: false` if air-gapped); and **Vibe Kanban (`B`)** for hard-disabled local telemetry. Below them, **`C`**-tier tools (**Orca**, **Pi**, **Happy**, **Goose**) offer strong core hygiene or cleanable mitigations (`DO_NOT_TRACK=1` on Orca, `--offline` on Pi, mobile opt-out on Happy, `GOOSE_TELEMETRY_OFF=1` on Goose).
3. **Never rely on `"anonymous"` marketing or `DO_NOT_TRACK` alone:** Most `D`/`F` tools combine `"anonymous"` or `"no telemetry"` docs/UI copy with plaintext email identification, hardware/install IDs created before opt-out, zero GeoIP suppression, or direct opt-out bypasses. Refer to Section 7 of [`report.md`](./report.md) for verified per-platform lockdown settings.
