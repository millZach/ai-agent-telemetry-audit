# Cross-Ecosystem Forensic Telemetry & Privacy Audit: T3 Code Peers & Open-Source Agent Harnesses

**Audit Scope:** Static, read-only source audit of **25 public open-source repositories** — **Group A** (13 multi-agent desktop/web GUIs closest to T3 Code, plus T3 Code baseline vs. live `HEAD` delta verification) and **Group B** (12 major open-source agent harnesses and coding CLIs).  
**T3 Code Baseline Reference:** `pingdotgg/t3code` @ `4c2e2b373433b729b4080f8bab42aa0754b63304` (prior baseline audit compared against live `HEAD` `2b84f486`)  
**Methodology & Constraints:**
- Shallow-cloned (`git clone --depth 1 --single-branch --no-tags`) all 25 verified repositories under `repos/<slug>` and recorded exact `git rev-parse HEAD` 40-char commit SHAs and commit timestamps in [`repos-manifest.json`](./repos-manifest.json).
- Zero builds, zero package installs (`npm install`, `cargo build`, etc.), and zero test executions were performed; no real home directory credential or configuration files (`~/.claude`, `~/.codex`, `~/.t3`, `~/.ssh`, keychains, etc.) were read or modified.
- All findings trace directly to inspected source lines (`file:line`) preserved in the 25 per-platform audit reports under [`audits/`](./audits/).

### Repository Discovery, Redirects, Archivals & Closed-Source Boundaries
Every target platform requested in Group A and Group B is publicly open-source at the source layer; canonical GitHub redirects, rebrands, archivals, and closed-source companion boundaries were verified before auditing:
- **Redirects / Renames:** `superset-sh/superset` → `ParadevAI/Paradev`; `getAsterisk/claudia` → `winfunc/opcode`; `sst/opencode` → `anomalyco/opencode` (default branch `dev`; audited at v2 monorepo layout); `All-Hands-AI/OpenHands` → `OpenHands/OpenHands` (currently OpenHands Agent Canvas `@openhands/agent-canvas` v`1.45.0`; Python `openhands-agent-server` and `openhands-automation` reside in external sibling repos); `block/goose` → `aaif-goose/goose`; `badlogic/pi-mono` → `earendil-works/pi`.
- **Rebrands / Archivals:** `stravu/crystal` was deprecated `2026-02-26` and succeeded by `nimbalyst/nimbalyst` (both audited); `RooCodeInc/Roo-Code` was archived `2026-05-15` after stripping telemetry and cloud plumbing in PRs `#12324` and `#12328` (final commit audited).
- **Additional Group A Discovery Peers Included:** `slopus/happy` (`Happy`, native mobile/CLI/Mac/server monorepo), `iOfficeAI/AionUi` (`AionUi`), and `winfunc/opcode` (`Opcode`).

### Privacy Rating Scale
| Rating | Definition | Live `HEAD` Count (25 Repos) |
|---|---|---|
| **`A` — High-Privacy (Zero Telemetry or Fail-Closed Opt-In)** | Zero product telemetry/analytics/crash/remote-telemetry SDKs active, OR strictly fail-closed opt-in architecture (all telemetry, OTLP, crash uploads, and SQLite/install-ID creation OFF by default with clean opt-out and zero third-party analytics SDKs). | **`B` — High-Privacy (Hard-Disabled Local w/ Minor Boot Plumbing)** | Local product telemetry and crash SDKs are hard-disabled (or zero third-party analytics SDKs ship locally) and no default-on analytics leave the app, yet minor runtime caveats persist (e.g., unconditional startup hardware-derived local/Relay user ID generation plus un-gated catalog/update/widget polling and operator-only remote telemetry). | **1** (`Vibe Kanban`) |

## 1. Executive Summary & Master Comparison Matrix

Across all 25 audited open-source platforms, only **3 platforms earn `A`** (`Aether`, `Roo Code [Archived]`, and `Hermes`) and **1 earns `B`** (`Vibe Kanban`) for avoiding active default-on product telemetry, while **not a single default-on platform achieved an unblemished opt-out standard** (honoring `DO_NOT_TRACK`, zero pre-consent beacons, full GeoIP/model masking, and accurate docs). Four platforms with strong core hygiene or minimal footprints form a distinct **`C` middle tier** (`Orca`, `Happy`, `Goose`, `Pi`), leaving **11 platforms in `D`** and **6 live platforms in `F`** alongside T3 Code's baseline commit:
- **`DO_NOT_TRACK` is virtually unsupported:** Only **`Orca`** cleanly honors `DO_NOT_TRACK` (`1`/`true`, disabling both PostHog and support diagnostic uploads at `src/main/telemetry/consent.ts:37-53`). **`Pane`** honors `DO_NOT_TRACK=1` partially (ignoring `true` and still running `gh api user` + writing `installId`/PII to `config.json`), and **`OpenHands`** honors `navigator.doNotTrack`/`DO_NOT_TRACK=1` partially (bypassed by prebuilt browser SPAs lacking `AGENT_CANVAS_DISABLE_TELEMETRY=1`, `submitPrivateFeedback`, and `AUTOMATION_POSTHOG_API_KEY`). All other **22 platforms ignore `DO_NOT_TRACK`**.
- **IP/GeoIP suppression is rare:** Despite 13+ platforms using PostHog directly or through closed-source proxies, only **`Happy`** (`/batch/` `$ip: null` + `$geoip_disable: true`, though missed on `/flags?v=2`) and **`Orca`** (`disableGeoip: true`, `$process_person_profile: false`) suppress PostHog GeoIP (with `OpenHands` suppressing IP only on manual `submitPrivateFeedback()`).
- **Custom/private model names leak widely:** **`Aether`**, **`Roo Code`**, **`Vibe Kanban`**, **`Emdash`**, **`Crystal`**, **`Orca`**, **`Traycer`**, **`Happy`**, **`T3 Code` Live `HEAD`** (fixed in `#42465` to `custom:<driver>`), and **`Pi`** (toward `pi.dev`) keep private/custom model IDs out of telemetry; **`Paradev`** (Mobile/Slack/Leaderboard), **`Nimbalyst`**, **`AionUi`** (daily logs), **`Codex CLI`**, **`Gemini CLI`**, **`OpenHands`**, **`Cline`**, **`Aider`** (`.aider.model.metadata.json`), **`Goose`**, **`Continue`** (OTEL/DevData), **`Kilo Code`**, **`OpenCode`** (when OTLP enabled), and **`Hermes`** (when opted in with non-Azure `base_url`) expose custom/local model names verbatim.
- **T3 Code trajectory (`4c2e2b37` → `2b84f486`):** Over 152 commits on `2026-11-24`, T3 Code removed its two sharpest `F`-tier practices (`~/.codex/auth.json` + `~/.claude.json` telemetry harvesting in `#42299`, and verbatim custom model leakage in `#42465`) alongside fixing desktop/browser/mobile relay races and isolating `agent.feedback` (`D`), yet left default-on analytics with zero UI/config/CLI opt-out, ignored `DO_NOT_TRACK`, unconditional `<stateDir>/anonymous-id` generation, unsalted SHA-256 hashing, missing PostHog IP suppression behind `ingest.t3.codes`, and Relay Worker Axiom `relay.edge.country`/Clerk `user.id` logging unresolved.
